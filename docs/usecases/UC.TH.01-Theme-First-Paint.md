# UC.TH.01 — Start in the stored theme

Related requirements: FR.9.14. Test cases: [TC.TH.01](/docs/testcases/TC.TH.01-Theme-First-Paint.md).

## UC.TH.01 — Open Tessyn with a stored theme
**Actor:** the User. **Precondition:** a theme is stored (Light or Dark) and Windows may be set to the other.
**Main flow:** 1. The User starts Tessyn (also after a self-update restart, maximised). 2. The first paint is in the stored theme: window frame, backdrop and controls agree. 3. The User never has to switch the theme back and forth to get a correct window.
**Covers:** FR.9.14.
