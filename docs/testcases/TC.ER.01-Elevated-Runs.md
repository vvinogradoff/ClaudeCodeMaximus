# TC.ER.01 — Elevated runs requested by an agent

Related requirements: [FR.15.16–FR.15.20](/docs/requirements/FR.15-Agent-Orchestration.md), [FR.23.31, FR.23.32](/docs/requirements/FR.23-Focus-View.md), [FR.32.16](/docs/requirements/FR.32-Client-Hosting.md); wire: tdcp-spec 10.A13. Use cases: [UC.ER.01](/docs/usecases/UC.ER.01-Elevated-Runs.md).

**Legend.** UNIT = xUnit in `TessynDesktop.Tests` (module over a temp run-folder root, `FakeTimeProvider`, fake scheduler, fake attention service, fake notifier); WRAPPER = xUnit that runs the **real wrapper script without elevation** (`powershell.exe -EncodedCommand`) in a temp folder against real `cmd.exe`; CONTRACT = wire tests with golden files; VM = WPF view-model and control tests; E2E = `tools\e2e\Run-WpfE2E.ps1` (WPF) or `dotnet test code/Tessyn.Web.E2E.Tests` (web); MANUAL = by the Architect.

**The elevation seam.** A Windows administrator prompt can't be clicked by a test (it runs on the secure desktop), and the E2E account has no UAC. So the tests never elevate: `IElevatedRunLauncher` (FR.32.16) has the fake `FakeElevatedRunLauncher`, which starts the daemon's launch description **without** elevation and can be told per run to `accept`, `decline` (throws Win32 error 1223), `fail` (throws another error) or `hang` (never reports). Unit, contract and VM tests inject it; the WPF E2E tests select it with `--test-window --elevated-launcher=fake:<mode>` (needs the Architect's approval, see the FR.32.16 note). What the fake does not prove — that the real prompt appears, that the process really is elevated, and that a normal WPF can stop it — is covered by the MANUAL tests.

**Fixture E.** Registered projects: **Alpha** (`C:\Proj\Alpha`) and **Beta** (`C:\Proj\Beta`); existing folders `C:\Proj\Alpha\src`, `C:\Proj\Alpha-wt-fix`, `C:\Proj\Alpha-wt-fix\src`, `C:\Proj\Alpha2`, `C:\Proj\Alpha-wt`, `C:\Proj\Alphawt-x`, `C:\Proj\Other`, `D:\Alpha-wt-x`, and a junction `C:\Proj\Alpha\link` to `C:\Windows`. Sessions: top-level **Lead** (working dir `C:\Proj\Alpha`), its worker **Wrk** (depth 1, working dir `C:\Proj\Alpha-wt-fix`), and a second top-level session **Other** (`C:\Proj\Beta`). Time is `FakeTimeProvider`.
